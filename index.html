Scripting Language Guide

Use this tool to render project metadata as HTML elements. You can type commands in the text box above and click "Run Script", or provide them directly in the URL.

Note: All commands must be in lowercase.

URL-based Scripting

To run a script from the URL, use the render query parameter. You can use multiple render parameters for multiple commands.

Format: ?render=<data_source>_as_<element_type>

Example: ?render=project_title_as_heading_one&render=creator_profile_as_link

Available Data Sources

  • project_title: The title of the current project.
  • project_description: The description of the current project.
  • creator_username: The username of the project creator.
  • creator_avatar_url: The URL for the creator's avatar image.
  • creator_profile: An object containing the creator's username and profile URL. Used with the link element.

Rendering Modes

  1. As an Element: Use data_source_as_element_type to wrap the data in a specific HTML element.
  2. As Plain Text: Use just the data_source name to render the raw data as text.

Available Element Types

  • heading_one, heading_two: Heading elements (h1, h2).
  • paragraph: A paragraph element.
  • division: A division (container) element.
  • span: An inline text container.
  • image: An image element. Best used with a URL data source like creator_avatar_url.
  • link: An anchor/link element. Best used with the creator_profile data source.

Simple Commands

Some commands don't require a data source.

  • horizontal_rule: Renders a horizontal line (`<hr>`).

Examples

Display the project title as a main heading, followed by a link to the creator's profile.

project_title_as_heading_one
creator_profile_as_link

Display the creator's avatar, followed by their username as plain text, and then the project description.

creator_avatar_url_as_image
creator_username
project_description_as_paragraph
